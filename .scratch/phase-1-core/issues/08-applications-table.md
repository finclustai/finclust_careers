# 08 — Cross-job Applications table

Status: ready-for-human
Blocked by: 05, 03

The list view for work that spans vacancies. Columns: candidate, phone, profile,
job, source, applied date, status, actions.

- Search across name, phone, email, Application Reference and job title
- Filters: job, profile, source, status, date range, experience, recruiter.
  Combinable, reflected in the URL so a filtered view is shareable
- Offset pagination with a capped page size. Marked with the known ceiling
- Empty state explains the next action rather than showing blank space
