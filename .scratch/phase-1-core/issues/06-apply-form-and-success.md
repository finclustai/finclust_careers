# 06 — Candidate apply form and success screen

Status: ready-for-human
Blocked by: 05

Mobile-first, correct at 375px. Mandatory: full name, mobile, profile, PDF
Resume. Optional: email, location, experience, current company, notice period,
expected salary, LinkedIn.

- Upload begins on file select, in the background, while the rest is filled in
- Inline validation on blur, errors below the field with `role="alert"`
- PDF-only stated before the picker opens, not after failure
- Consent checkbox and privacy line
- 16px inputs, 44px touch targets

Success screen presents the Application Reference as a stamped ticket, the one
place the reference aesthetic runs in full.
